### quiz03

题目：

```
设定一组四码的数字作为谜底，另一方猜每猜一个数，出数者就要根据这个数字给出提示，提示以XAYB形式呈现，直到猜中位置。

其中X表示位置正确的数的个数(数字正确且位置正确)，而Y表示数字正确而位置不对的数的个数例如，当谜底为8123，而猜谜者猜1052时，出题者必须提示0A2B。例如，当谜底为5637，而猜谜者猜4931时，出题者必须提示1A0B。当前已知N组猜谜者猜的数字与提示，如果答案确定，请输出答案，不确定则输出NA。

输入描述
第一行输入一个正整数，0< N < 100.
接下来N行，每一行包含一猜测的数字与提示结果

输出描述
输出最后的答案，答案不确定则输出NA。

示例1：
输入
6
4815 1A1B
5716 0A1B
7842 0A1B
4901 0A0B
8585 3A0B
8555 2A1B

输出
3585
```

**解题思路**

这是一个经典的 **Bulls and Cows（猜数字）** 逆推问题，核心是：**枚举候选答案 → 用所有历史提示去过滤 → 看剩下的候选是否唯一**。

1. 枚举空间

谜底是一个 4 位编码，每一位是 `0~9`，且允许数字重复（本题答案 `3585` 就重复了 `5`）。因此可以枚举 `0000` 到 `9999`（共 10000 个），格式化成 4 位字符串处理；如果题目保证是“不含前导零的四位数字”，枚举 `1000~9999` 也可以，本例结果一致。

2. 如何正确计算 X A Y B（易错点）

给定候选 `cand` 和猜测 `guess`：

- **A（位置正确的个数）**：逐位比较，`cand[i] == guess[i]` 的个数。
- **数字正确的总数（含位置正确的）**：对 `0~9` 每个数字 `d`，取它在 `cand` 中出现次数与在 `guess` 中出现次数的**较小值**，求和。
- **B（数字正确但位置错误）**：`数字正确总数 - A`。

> ⚠️ **绝对不能**用 `Set` 或“逐个去另一个串里找”的方式算 B，否则遇到**重复数字**（如本题的 `5`、`8` 多次出现）会算错。必须用“计数取 min”的方法。

3. 判定

- 把每一条 `(guess, XAYB)` 都拿来检验候选，只有**全部满足**的候选才保留。
- 最后：
  - 恰好剩下 **1 个** → 输出它（答案确定）；
  - 剩下 **0 个或多个** → 输出 `NA`。

------

**完整 Java 参考实现**

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = Integer.parseInt(in.next());

        List<String> guesses = new ArrayList<>();
        List<int[]> hints = new ArrayList<>(); // 每个元素为 {A, B}

        for (int i = 0; i < n; i++) {
            String g = in.next();          // 猜测的4位数字，如 "4815"
            String hint = in.next();       // 提示，如 "1A1B"
            int a = hint.charAt(0) - '0';  // X
            int b = hint.charAt(2) - '0';  // Y（格式固定为 X A Y B）
            guesses.add(g);
            hints.add(new int[]{a, b});
        }

        List<String> candidates = new ArrayList<>();
        // 枚举所有 4 位编码：0000 ~ 9999（若限定无前导零，改为 i<=9999 && i>=1000 即可）
        for (int i = 0; i <= 9999; i++) {
            String cand = String.format("%04d", i);
            boolean ok = true;
            for (int j = 0; j < n; j++) {
                if (!match(cand, guesses.get(j), hints.get(j)[0], hints.get(j)[1])) {
                    ok = false;
                    break;
                }
            }
            if (ok) {
                candidates.add(cand);
            }
        }

        // 唯一则输出，否则输出 NA
        if (candidates.size() == 1) {
            System.out.println(candidates.get(0));
        } else {
            System.out.println("NA");
        }
        in.close();
    }

    /**
     * 判断候选答案 cand 面对猜测 guess 时，是否得到 aAbB
     */
    static boolean match(String cand, String guess, int a, int b) {
        int A = 0;
        int[] cntC = new int[10]; // cand 中各数字出现次数
        int[] cntG = new int[10]; // guess 中各数字出现次数

        for (int i = 0; i < 4; i++) {
            char c = cand.charAt(i);
            char g = guess.charAt(i);
            if (c == g) {
                A++; // 数字和位置都对
            }
            cntC[c - '0']++;
            cntG[g - '0']++;
        }

        int total = 0; // 数字正确的总数（位置对 + 位置错）
        for (int d = 0; d < 10; d++) {
            total += Math.min(cntC[d], cntG[d]);
        }
        int B = total - A; // 数字对但位置错

        return A == a && B == b;
    }
}
```
