# 数据库常用函数

## 时间函数

以下是 MySQL 中常用的时间/日期函数，按用途分类整理：

------

### 1 获取当前时间

| 函数        | 返回值                         | 示例结果              |
| ----------- | ------------------------------ | --------------------- |
| `NOW()`     | 当前日期和时间                 | `2026-10-25 14:30:00` |
| `CURDATE()` | 当前日期                       | `2026-10-25`          |
| `CURTIME()` | 当前时间                       | `14:30:00`            |
| `SYSDATE()` | 当前日期和时间（函数执行时刻） | `2026-10-25 14:30:01` |

> `NOW()` 和 `SYSDATE()` 区别：`NOW()` 在整个语句执行中保持不变，`SYSDATE()` 每次调用都取实时时间。

------

### 2 提取日期/时间的某部分

| 函数              | 说明             | 示例                                  |
| ----------------- | ---------------- | ------------------------------------- |
| `YEAR(date)`      | 提取年份         | `YEAR('2026-10-25')` → `2026`         |
| `MONTH(date)`     | 提取月份         | `MONTH('2026-10-25')` → `10`          |
| `DAY(date)`       | 提取日           | `DAY('2026-10-25')` → `25`            |
| `HOUR(time)`      | 提取小时         | `HOUR('14:30:00')` → `14`             |
| `MINUTE(time)`    | 提取分钟         | `MINUTE('14:30:00')` → `30`           |
| `SECOND(time)`    | 提取秒           | `SECOND('14:30:00')` → `0`            |
| `WEEK(date)`      | 一年中的第几周   | `WEEK('2026-10-25')` → `43`           |
| `QUARTER(date)`   | 季度（1-4）      | `QUARTER('2026-10-25')` → `4`         |
| `DAYOFWEEK(date)` | 星期几（1=周日） | `DAYOFWEEK('2026-10-25')` → `1`       |
| `WEEKDAY(date)`   | 星期几（0=周一） | `WEEKDAY('2026-10-25')` → `6`         |
| `DAYNAME(date)`   | 星期名称         | `DAYNAME('2026-10-25')` → `Sunday`    |
| `MONTHNAME(date)` | 月份名称         | `MONTHNAME('2026-10-25')` → `October` |

------

### 3 日期格式化

| 函数                        | 说明           | 示例                                                   |
| --------------------------- | -------------- | ------------------------------------------------------ |
| `DATE_FORMAT(date, format)` | 按格式输出日期 | `DATE_FORMAT(NOW(), '%Y-%m-%d')` → `2026-10-25`        |
| `TIME_FORMAT(time, format)` | 按格式输出时间 | `TIME_FORMAT(NOW(), '%H:%i:%s')` → `14:30:00`          |
| `STR_TO_DATE(str, format)`  | 字符串转日期   | `STR_TO_DATE('2026-10-25', '%Y-%m-%d')` → `2026-10-25` |

**常用格式化符号：**

- `%Y` — 四位年份
- `%y` — 两位年份
- `%m` — 月份（01-12）
- `%d` — 日（01-31）
- `%H` — 24小时制小时（00-23）
- `%h` — 12小时制小时（01-12）
- `%i` — 分钟（00-59）
- `%s` — 秒（00-59）
- `%W` — 星期名称
- `%M` — 月份名称

------

### 4 日期计算与加减

| 函数                                 | 说明         | 示例                                                      |
| ------------------------------------ | ------------ | --------------------------------------------------------- |
| `DATE_ADD(date, INTERVAL expr unit)` | 日期加法     | `DATE_ADD('2026-10-25', INTERVAL 7 DAY)` → `2026-11-01`   |
| `DATE_SUB(date, INTERVAL expr unit)` | 日期减法     | `DATE_SUB('2026-10-25', INTERVAL 1 MONTH)` → `2026-09-25` |
| `DATEDIFF(date1, date2)`             | 相差天数     | `DATEDIFF('2026-11-01', '2026-10-25')` → `7`              |
| `TIMEDIFF(time1, time2)`             | 相差时间     | `TIMEDIFF('18:00:00', '14:30:00')` → `03:30:00`           |
| `TIMESTAMPDIFF(unit, start, end)`    | 按单位算差值 | `TIMESTAMPDIFF(MONTH, '2026-01-01', '2026-10-25')` → `9`  |

**INTERVAL 支持的单位：**

```
YEAR`, `MONTH`, `DAY`, `HOUR`, `MINUTE`, `SECOND`, `WEEK`, `QUARTER
```



# 常见场景

## 成绩排名

```
+-------------+---------+
| Column Name | Type    |
+-------------+---------+
| id          | int     |
| score       | decimal |
+-------------+---------+
id 是该表的主键（有不同值的列）。
该表的每一行都包含了一场比赛的分数。Score 是一个有两位小数点的浮点值。
```

编写一个解决方案来查询分数的排名。排名按以下规则计算:

- 分数应按从高到低排列。
- 如果两个分数相等，那么两个分数的排名应该相同。
- 在排名相同的分数后，排名数应该是下一个连续的整数。换句话说，排名之间不应该有空缺的数字。

按 `score` 降序返回结果表。

查询结果格式如下所示。

```
输入: 
Scores 表:
+----+-------+
| id | score |
+----+-------+
| 1  | 3.50  |
| 2  | 3.65  |
| 3  | 4.00  |
| 4  | 3.85  |
| 5  | 4.00  |
| 6  | 3.65  |
+----+-------+
输出: 
+-------+------+
| score | rank |
+-------+------+
| 4.00  | 1    |
| 4.00  | 1    |
| 3.85  | 2    |
| 3.65  | 3    |
| 3.65  | 3    |
| 3.50  | 4    |
+-------+------+
```

sql：

```sql
SELECT
  S1.score,
  (
    SELECT
      COUNT(DISTINCT S2.score)
    FROM
      Scores S2
    WHERE
      S2.score >= S1.score
  ) AS 'rank'
FROM
  Scores S1
ORDER BY S1.score DESC
;


或者


SELECT
s.score,
(

SELECT COUNT(temp.score)
FROM (

SELECT 
s2.score
FROM scores s2
GROUP BY score

) AS temp 
WHERE temp.score >= s.score

) AS 'rank'
FROM scores s
ORDER BY s.score DESC
;
```
