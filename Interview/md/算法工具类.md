# 算法工具类

## Math

### pow

 `java.lang.Math` 的**静态方法**

Math.pow(a, b) —— 求 a 的 b 次方

```java
double x = Math.pow(2, 10);      // 1024.0
double y = Math.pow(4, 0.5);     // 2.0   开平方的另一种写法
double z = Math.pow(2, -1);      // 0.5   负指数 = 倒数
double w = Math.pow(27, 1.0/3);  // 3.0   开立方
```

**签名只有一种**：`double pow(double a, double b)`，参数和返回值都是 `double`。

pow 走的是浮点算法，超出 double 的 53 位有效精度就会出错。要求精确整数结果时用 BigInteger.pow()。



### sqrt

 `java.lang.Math` 的**静态方法**

Math.sqrt(a) —— 开平方

```java
double r = Math.sqrt(16);     // 4.0
double r2 = Math.sqrt(2);     // 1.4142135623730951
Math.sqrt(-1);                // NaN（负数开方，不抛异常）
Math.sqrt(Double.NaN);        // NaN
Math.sqrt(Double.POSITIVE_INFINITY);  // Infinity
```

**签名**：`double sqrt(double a)`。



### max

 `java.lang.Math` 的**静态方法**

Math.max(a, b) —— 取较大值

```java
Math.max(3, 5);          // 5
Math.max(-2.5, -7.1);    // -2.5
Math.max(10L, 20L);      // 20L
Math.max(1.5f, 2.5f);    // 2.5f
```

**有四个重载**：`max(int,int)`、`max(long,long)`、`max(float,float)`、`max(double,double)`。

## Map

### LinkedHashMap

​		**唯一有序的 HashMap 子类是 `LinkedHashMap`**。

​		它在 HashMap 的桶结构之外，额外维护了一条贯穿所有节点的**双向链表**（`before`/`after` 指针），迭代时走的就是这条链表。

```java
// 1) 插入顺序（默认）——按 put 的先后
Map<String, Integer> m = new LinkedHashMap<>();
m.put("b", 1); m.put("a", 2); m.put("c", 3);
System.out.println(m.keySet());   // [b, a, c]

// 2) 访问顺序（accessOrder=true）——每次 get/put 都把该元素挪到末尾
Map<String, Integer> lru = new LinkedHashMap<>(16, 0.75f, true);
lru.put("a", 1); lru.put("b", 2); lru.put("c", 3);
lru.get("a");                      // 访问 a，a 被挪到最末
System.out.println(lru.keySet());  // [b, c, a]
```

**坑点提醒**：插入顺序模式下，对已存在的 key 重新 `put` **不会**改变它的位置（只更新 value）；而访问顺序模式下 `get` 都会改顺序 —— 所以遍历过程中别顺手 `get`，会打乱迭代。



### TreeMap

TreeMap 的特性

- **自动按键排序**：默认按自然顺序升序排列
- **红黑树实现**：插入和查找的时间复杂度为 O(log n)
- **适用于需要排序的场景**

### sort

**同一字母的大小写同时存在时，按照输入顺序排列**。这就是要求**稳定排序**（stable sort）。

示例：

```java
// 要么 x1<x2           x正序
//要么x1==x2 目y1<y2    y正序
resList.sort((a,b) -> {
            if (a.x != b.x){
                return Integer.compare(a.x,b.x);
            }
            return Integer.compare(a.y,b.y);
        });
```



### reverse

Collections.reverse() 是 Java 集合框架中用于反转列表元素顺序的静态方法。

```java
List<String> list = new ArrayList<>(Arrays.asList("A", "B", "C", "D"));
Collections.reverse(list);
System.out.println(list);  // 输出：[D, C, B, A]
```

## PriorityQueue

​		PriorityQueue 是 Java 集合框架中的一个无界优先队列，基于优先级堆（最小堆）实现。它允许我们按照元素的自然顺序或自定义比较器来排序元素，而不是按照插入顺序。

**常用构造方法**

```java
// 默认容量11，按自然顺序排序
PriorityQueue<Integer> pq1 = new PriorityQueue<>();

// 指定初始容量
PriorityQueue<Integer> pq2 = new PriorityQueue<>(20);

// 使用自定义比较器（最大堆示例）
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);

// 从已有集合创建
PriorityQueue<String> pq3 = new PriorityQueue<>(existingCollection);
```

------

**核心 API**

**添加元素**

```java
pq.offer(5);   // 推荐，容量无限制时不会抛异常
pq.add(3);     // 内部调用 offer()
```

**访问元素**

```java
pq.peek();      // 获取队首（最小元素），为空返回 null
pq.element();   // 同上，但空时会抛 NoSuchElementException
```

**删除元素**

```java
pq.poll();      // 移除并返回队首，为空返回 null
pq.remove();    // 同上，空时抛异常
pq.remove(obj); // 移除指定对象（O(n)）
```

**其他**

```java
pq.size();
pq.isEmpty();
pq.clear();
pq.contains(obj);  // O(n)
```

## String

### indexOf

indexOf 是 Java 中用于查找子字符串或字符在字符串中首次出现位置的方法。

一、四种重载形式

1. `indexOf(int ch)` - 查找字符

```java
String str = "Hello World";
int pos = str.indexOf('o');     // 返回 4
int pos2 = str.indexOf('x');    // 返回 -1（未找到）
```

2. `indexOf(int ch, int fromIndex)` - 从指定位置开始查找字符

```java
String str = "Hello World";
int pos = str.indexOf('o', 5);  // 从索引5开始找，返回 7
int pos2 = str.indexOf('o', 8); // 从索引8开始找，返回 -1
```

3. `indexOf(String str)` - 查找子字符串

```java
String str = "Hello World Hello";
int pos = str.indexOf("World");    // 返回 6
int pos2 = str.indexOf("Java");    // 返回 -1
```

4. `indexOf(String str, int fromIndex)` - 从指定位置开始查找子字符串

```java
String str = "Hello World Hello";
int pos = str.indexOf("Hello", 1); // 从索引1开始找，返回 12
int pos2 = str.indexOf("Hello", 13);// 从索引13开始找，返回 -1
```

二、返回值说明

| 情况         | 返回值                                |
| ------------ | ------------------------------------- |
| 找到匹配项   | 返回第一个匹配项的起始索引（从0开始） |
| 未找到匹配项 | 返回 -1                               |
